# learnDSH

学习 DeepSeek Harness（dsh）的成果仓库。

## 内容

- `dsh-book.html` — 交互式导读书（单文件 HTML，直接打开即可）：米色纸张风、左侧章节导航、单步循环模拟器、机判自测、四级提示阶梯、学习进度记录。
- `dsh-visual-guide.html` — 早期版可视化页面。
- `DSH-代码报告与使用指南.md` — 源码分析报告与上手指南。
